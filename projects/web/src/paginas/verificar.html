Verificar un certificado

Comprueba que un certificado de la Academia HyperEZ es auténtico: escanea su QR o pega aquí su enlace de verificación.

Cómo funciona

🎓

Se gana jugando

El certificado se obtiene al completar las 10 misiones de la Academia HyperEZ y aprobar su examen final.

🔐

Código único

Cada certificado tiene un código HZ-AAAA-XXXX-XXXX calculado (SHA-256) a partir del nombre, la nota y la fecha.

✅

A prueba de retoques

Esta página recalcula el código con los datos del QR: si alguien cambia el nombre o la nota, el código ya no coincide con el impreso.

Compara siempre el código que muestra esta página con el impreso en el certificado. La web de HyperEZ no tiene servidor: no guarda una lista de los certificados emitidos, y la comprobación se hace en tu navegador.
