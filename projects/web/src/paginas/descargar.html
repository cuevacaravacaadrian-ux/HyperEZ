Windows

El instalador deja listo el lenguaje en el sistema (orden hyper, doble clic en los .hez) y, si quieres, HyperEZ Editor y la extensión de VS Code. No necesita administrador.

⬇ Instalador para Windows
  • HyperEZ-Setup-{{version}}.exe~14 MB
  • hyperez-editor.exe (HyperEZ Editor portátil)
  • hyper.exe (el lenguaje, portátil)

Linux

Un paquete con hyper, los ejemplos y la documentación. Funciona en casi cualquier distribución x64 (glibc 2.35 o posterior).

⬇ Paquete para Linux (x64)
  • HyperEZ-{{version}}-linux-x64.tar.gz

macOS

Un paquete para Mac con Apple Silicon (M1 o posterior), con un instalador sencillo para la terminal.

⬇ Paquete para macOS (Apple Silicon)
  • HyperEZ-{{version}}-macos-arm64.tar.gz
Windows
  1. Abre HyperEZ-Setup.exe y pulsa Instalar.
  2. Elige si quieres HyperEZ Editor y la extensión de VS Code.
  3. Abre HyperEZ Editor desde el menú Inicio y pulsa F5.

Si Windows avisa de que el archivo es poco común, pulsa Más información → Ejecutar de todas formas: el instalador no está firmado.

Linux y macOS
tar -xzf HyperEZ-*.tar.gz
cd HyperEZ-*
sh install.sh
hyper version

Lo instala en tu carpeta personal (~/.local); no necesita sudo.

Visual Studio Code
  1. Pestaña Extensiones → busca HyperEZ.
  2. O descarga el .vsix y elige Instalar desde VSIX…

En Windows la extensión ya trae hyper.exe: funciona sin instalar nada más.

Sin instalar nada

El editor en el navegador ejecuta HyperEZ de verdad (compilado a WebAssembly) con explorador de archivos, errores en vivo y autocompletado. Tu código no sale de tu navegador.

Todas las versiones

Los cambios de cada versión están en Versiones, y todos los archivos en la página de versiones de GitHub. El código fuente se compila con CMake y GCC o Clang: mira Instaladores y compilación.
