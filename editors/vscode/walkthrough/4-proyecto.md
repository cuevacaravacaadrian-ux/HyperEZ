# Un proyecto completo

**HyperEZ: Nuevo proyecto** crea una carpeta ordenada (`main.hz`, `src/`, `tests/`, `datos/`) con un ejemplo que funciona desde el primer momento:

| Tipo | Qué crea |
|---|---|
| Juego | un juego de consola con teclado |
| App | una aplicación con menú y datos guardados |
| IA | una red neuronal que aprende de un CSV |
| Script | una herramienta de línea de órdenes |
