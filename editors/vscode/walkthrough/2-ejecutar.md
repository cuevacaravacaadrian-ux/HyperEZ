# Ejecutar

- **F5** (o el botón ▶ arriba a la derecha) ejecuta el archivo en una terminal.
- **Ctrl+Alt+F5** activa el **modo watch**: cada vez que guardas (Ctrl+S) el programa se vuelve a ejecutar solo. Perfecto para ver los resultados al instante.
- **Ctrl+Mayús+F5** comprueba los errores sin ejecutar.
