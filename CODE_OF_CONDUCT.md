# Código de conducta

HyperEZ es un proyecto para aprender y crear. Queremos que cualquiera, sepa mucho o poco, se sienta bienvenido.

## Lo que esperamos

- Trato amable y respetuoso, también cuando no estamos de acuerdo.
- Paciencia con quien empieza: todas las preguntas son válidas.
- Críticas sobre el código y las ideas, nunca sobre las personas.
- Reconocer el trabajo de los demás.

## Lo que no se acepta

- Insultos, burlas, acoso o comentarios discriminatorios de cualquier tipo.
- Publicar datos privados de otras personas.
- Cualquier conducta que haga que alguien se sienta inseguro o excluido.

## Qué pasa si no se cumple

Quien mantiene el proyecto puede editar o borrar comentarios, cerrar incidencias y, si hace falta, bloquear a quien no respete estas normas. Para avisar de un problema, escribe en privado al responsable del proyecto a través de su perfil de GitHub.

Este código se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
